Вход

Войдите через Яндекс, Mail.ru, Gmail или ORCID, чтобы подавать рукописи и сохранять черновики в учётной записи.

Вход работает только для провайдеров с настроенными ключами OAuth (Client ID и Secret). Пока ключи не заданы, кнопка показывает инструкцию — успешный вход не имитируется.

После настройки добавьте Redirect URI вида http://127.0.0.1:5173/api/auth/callback/… в кабинете провайдера. См. .env.example.
